qr-stream examples

Three small, real uses of the public API. Run them with pnpm examples:build and serve examples/dist/ over HTTPS or localhost.

  • Minimal sender — writer plus animated canvas.
  • Minimal receiver — camera, ZXing decoder, fountain reader.
  • React hooks — useQrStreamWriter and the camera/reader hooks.

Every page imports @orozcoh/qr-stream entries that this Vite config aliases to src/. A published host imports the package instead; nothing else changes.
